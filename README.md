# Product Management System

Система управления продуктами с REST API, реализующая CRUD-операции и расширенный поиск.

## Реализованные изменения

### Новый функционал
- Добавлена сущность `Product` с полями:
- id (Long)
- name (String)
- description (String)
- price (BigDecimal)

#### Реализованы CRUD-операции:
- Создание продукта
- Получение продукта по ID
- Обновление продукта
- Удаление продукта
- Расширенный поиск с возможностями:
- Поиск по части названия (без учета регистра)
- Сортировка результатов по цене (возрастание/убывание)

### Тестирование
Написаны юнит-тесты для:

- Репозитория (интеграционные тесты)
- Сервиса (Mockito)

Покрыты сценарии:

- Позитивные (успешные операции)
- Негативные (ошибки валидации, отсутствие данных)

## Инструкция по запуску

### Требования
- Java 17+
- Maven 3.8+ или Gradle 7+

### 1. Сборка проекта
```bash
# Для Maven
mvn clean package

# Для Gradle
gradle build
```

### 2. Запуск проекта
Запуск проекта осуществляется через `AccessingDataJpaApplication` класс

### 2. Отправка запросов
Запросы посылаются на адрес http://localhost:8080

Демо запрос по адресу http://localhost:8080/demo-search

Демо запрос поиска по адресу http://localhost:8080/demo-search
